# QQ 机器人配置说明

PST 可以主动连接同一台 Windows 电脑上的 NapCatQQ，通过 OneBot 11 在 QQ 群或私聊中提供服务器查询和有限的管理员操作。该功能不需要 DeepSeek，也不会开放新的监听端口。

## 1. 配置 NapCatQQ

1. 安装 NapCatQQ，登录专门用于机器人的 QQ 账号，并把该账号加入目标群。
2. 打开 NapCat WebUI 的“网络配置”。
3. 新建 **WebSocket 服务端（正向 WebSocket）**。
4. 监听主机填写 `127.0.0.1`，端口填写 `3001`。
5. 设置一段高强度 OneBot Token。不要把 NapCat WebUI 登录 Token 当作 OneBot Token。
6. 保存并启动该网络配置。

不要把 `3001` 暴露到公网，也不要在 WebSocket URL 查询参数中携带 Token。PST 只接受 `ws://127.0.0.1:<端口>` 或 `ws://[::1]:<端口>`。

## 2. 配置 PST

1. 登录 PST 管理员界面，打开“QQ 机器人”。
2. 地址填写 `ws://127.0.0.1:3001`。
3. 填写与 NapCat 完全相同的 OneBot Token。可以使用页面的“随机生成”，再把生成值复制到 NapCat。
4. 点击“测试连接”。成功后读取群列表。
5. 选择允许使用机器人的群，填写管理员 QQ，并设置查询、写操作和通知权限。
6. 保存配置。PST 会热重连，不需要重启 PST 或 PalServer。

群消息只有在 `@机器人` 时响应；非允许群会被忽略。私聊只接受配置中明确列出的管理员 QQ。

## 3. 不使用 AI 的基础命令

```text
@机器人 服务器状态
@机器人 现在谁在线
@机器人 查询 张三 在线时间
@机器人 石头还有多少
@机器人 石头在哪
@机器人 据点列表
@机器人 第一据点异常帕鲁
@机器人 配种提醒
@机器人 最近一次备份
@机器人 下次自动重启
```

管理员可按权限发起：

```text
@机器人 把旧基地改名为第一据点
@机器人 启动服务器
@机器人 重启服务器
@机器人 关服
```

机器人会先返回操作对象和六位验证码。必须由发起操作的同一 QQ，在同一群或同一私聊中于 60 秒内回复 `确认 123456`。验证码只能使用一次；执行前还会重新检查管理员和权限设置。

“关服”固定为平滑停止 PalServer 并保持关闭，不会被崩溃守护重新拉起。“关机”也只按关服理解，绝不会关闭 Windows 主机或 PST。

## 4. 可选 DeepSeek

DeepSeek 用于理解基础规则没有覆盖的自然语言说法，不是命令执行器。启用后填写 DeepSeek 官方 API Key，点击“测试 DeepSeek”。PST 固定使用 `deepseek-v4-flash`；旧版保存的 `deepseek-chat` 或 `deepseek-reasoner` 会在升级后自动迁移，不需要重新填写 API Key。

- 只有 DeepSeek API Key 会发送给 `https://api.deepseek.com`。
- OneBot Token、PST JWT、RCON/REST 密码、IP、本机路径和玩家技术 ID不会进入 AI 请求。
- 模型只能从 PST 注册的固定工具中选择；据点改名和 PalServer 控制仍必须二次确认。
- API Key 无效、额度不足、超时或返回非法工具时，PST 会继续使用基础命令。

## 5. 捣蛋喵回复风格

“回复风格”对固定命令、主动通知和 DeepSeek 同时生效，不配置 DeepSeek 也可以使用。管理员可以关闭人设，或在“克制、活泼、调皮”三档猫味中选择；默认使用“活泼”，并在服务器崩溃、备份失败和操作失败时自动切换为严肃语气。

PST 不开放完整系统提示词编辑。真实性、安全边界、管理员权限和二次确认规则始终由后端固定，角色文案不会改写数量、时间、状态、错误或六位确认码。

## 5. 主动通知

主动通知默认关闭，可分别启用：

- PalServer 意外退出；
- 崩溃守护自动重启；
- 计划重启开始；
- 备份失败；
- 配种产蛋提醒。

通知只能发送到“允许群”中的群。断线时 PST 最多在内存中暂存 100 条通知，连接恢复后补发一小时内的消息；PST 重启不会重放旧事件。

## 6. 常见问题

- **连接被拒绝**：确认 NapCat 的正向 WebSocket 服务端已启动，监听的是 `127.0.0.1`，端口与 PST 一致。
- **鉴权失败**：确认两边填写的是同一个 OneBot Token，而不是 WebUI 登录 Token。
- **群里没有响应**：确认群已加入允许列表，消息中确实 @了当前机器人账号。
- **能查询但不能重启**：确认发言 QQ 在管理员列表中，并开启了对应的独立权限。
- **DeepSeek 不可用**：直接发送“帮助”查看基础命令；基础功能不受影响。
